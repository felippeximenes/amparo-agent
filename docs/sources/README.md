# Fontes curadas (RAG)

Cada arquivo aqui representa uma fonte oficial curada manualmente sobre
BPC/LOAS — nunca um crawl automático. Precisão importa mais que cobertura
neste domínio.

Cabeçalho obrigatório em cada arquivo:

```
---
titulo: <nome da norma ou manual>
fonte: <URL ou referência oficial>
tipo: lei | decreto | instrucao_normativa | manual
coletado_em: <YYYY-MM-DD>
---
```

Fontes previstas para a Fase 1 do roadmap:

- Lei Orgânica da Assistência Social (Lei 8.742/93) e alterações
- Decreto 6.214/2007 (regulamenta o BPC)
- Instruções Normativas do INSS sobre o BPC
- Manuais oficiais do Meu INSS / gov.br/inss
